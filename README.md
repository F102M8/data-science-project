# 24-Hour Player Peak Analysis for Games on SteamDB

A data science project exploring what influences a game's **24-hour peak concurrent player count** and predicting that value using game information collected from [SteamDB](https://steamdb.info/).

## Project Workflow

- **Data Collection:** Web scraping to gather game information, including details and pricing.
- **Data Preprocessing:** Cleaning and preparing collected datasets for analysis.
- **Exploratory Data Analysis:** Investigating trends, distributions, and relationships in game data.
- **Modeling:** Applying data analysis and modeling techniques to explore the dataset further.

## Technologies

Python · Jupyter Notebook · Web Scraping · Data Analysis · Data Visualization
